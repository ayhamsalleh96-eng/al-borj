# البرج ديون — مشروع Flutter لأندرويد

يحتوي هذا المشروع على كود تطبيق «البرج ديون» وشعار Al Bori Telecom داخل `assets/albori_logo.jpg`، مع إعداد لإنشاء أيقونة التطبيق، وسير عمل لبناء APK تلقائياً عبر GitHub Actions.

## بناء ملف APK تلقائياً

أضفت سير العمل `.github/workflows/build-apk.yml` ليولّد ملفات منصة Android، ويثبّت الاعتماديات، وينشئ الأيقونة من الشعار، ثم يبني نسخة APK للإصدار.

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد باسم `albori-debt`.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build AlBori Debt APK** ثم **Run workflow**، أو ادفع commit إلى الفرع `main` أو `master`.
4. بعد انتهاء البناء بنجاح، افتح تشغيل workflow المكتمل، وانزل إلى **Artifacts**، ثم نزّل `albori-debt-apk`.
5. فك ضغط ملف Artifacts لتحصل على `app-release.apk` وانقله إلى هاتف Android للتثبيت.

## بيانات الدخول التجريبية
- المدير: `admin` / `1234`
- العامل: `worker` / `1111`

## ملاحظات مهمة قبل الاستخدام الحقيقي
- بيانات الزبائن والحركات محفوظة في الذاكرة فقط حالياً، وستضيع عند إغلاق التطبيق. أضف تخزيناً محلياً دائماً أو قاعدة بيانات قبل الاعتماد عليه في المتجر.
- بيانات الدخول تجريبية ومكتوبة داخل الكود، وليست نظام أمان مناسباً للاستخدام الفعلي.
- يمكن أن يجعل التسديد الأكبر من الرصيد حساب الزبون سالباً؛ راجع هذه السياسة قبل الاستخدام الفعلي.
- إعدادات البناء السحابي لا تعني أن APK بُني بالفعل؛ يلزم تشغيل الـ workflow في GitHub للحصول على ملف التثبيت.
